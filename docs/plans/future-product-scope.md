# Future Product Scope

Status: Parking lot

This document holds product-scope questions that are important, but not part of Phase 0.

Phase 0 is focused on the project foundation: stack, repository structure, development workflow, testing, CI, and database/schema setup. Product-scope decisions should be revisited when planning the first feature phase.

## Questions To Revisit

- Should the first MVP start with a narrow, easy-to-research citizenship scenario, or with a larger search audience such as US, Indian, Turkish, Russian, or EU citizens?
- Which destination countries should be included in the first dataset?
- Which route types belong in the first MVP?
- What should be explicitly out of scope for MVP?
- Should humanitarian and asylum-related routes be included in MVP, or added later with extra care?
- Should Pathport initially show only human-reviewed content, or allow clearly labeled AI-assisted drafts?
- Should country scores exist at all, or should the product rely on filters and comparable facts?
- How much cost-of-living data is useful before city-level data becomes necessary?
- What is the smallest dataset that can still prove the product concept?
- Should the first version be English-only?
- How should uncertainty, missing data, and outdated data be displayed?
- Should AI be used only internally for drafting, or should the product include user-facing AI features later?

## Notes

- Keep the first product slice small enough to feel finished.
- Prefer a narrow but polished dataset over broad, shallow coverage.
- Preserve source visibility and uncertainty labels from the beginning.
